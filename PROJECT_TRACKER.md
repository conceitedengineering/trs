## Brand Guardrails For Website Design
- Core promise: align how clients live and look for a more embodied life
- Desired emotional outcome: `Seen`, `Empowered`, `Grounded`
- Editorial direction: intimate, sensory, grounded, intentional, inspiring
- Tone: warm, concise, considered, gentle, real, with light wit
- Positioning: premium but approachable; luxury signal without elitist posture
- Content stance: avoid influencer mimicry, fear-based messaging, and generic advice
- UX stance: refined and straightforward navigation; editorial magazine meets educational course

## What Needs To Be Done

### 1) Discovery Consolidation
- Collect and organize all source docs (brand, messaging, IA, references)
- Convert client inputs into actionable website requirements
- Define success criteria for launch

### 2) Website Strategy
- Confirm site goals (business + user)
- Define target audience segments and top user journeys
- Finalize sitemap and page hierarchy
- Define content model per page type

### 3) UX + Content Planning
- Produce wireframe direction for key templates
- Map section-level content requirements
- Identify asset needs (imagery, icons, video, downloads)
- Flag any content gaps needing client input

### 4) Visual Design System (Web Application Layer)
- Translate brand system into web-ready rules for Squarespace
- Define typographic scale and spacing system
- Define color usage/accessibility standards
- Establish reusable section patterns/components

### 5) Squarespace Build
- Configure site structure/navigation in Squarespace
- Build templates/pages using approved design patterns
- Implement responsive behavior and QA across breakpoints
- Integrate forms, scheduling/class features, and key business flows

### 6) QA + Launch
- Run pre-launch QA (content, UX, responsiveness, accessibility)
- Validate SEO essentials (metadata, headings, URLs, redirects as needed)
- Perform stakeholder review + revision pass
- Publish and monitor post-launch issues
