# TRS Page Briefs (Phase 5 MVP)

## Usage
- These briefs are for design + build in Squarespace.
- Keep pages aligned to TRS guardrails: warm, concise, grounded, premium-not-elitist.
- Default interaction rule: clarity first, ornament second.

## Shared Global Rules
- **Primary conversion bias:** Member Space signup
- **Secondary conversion paths:** Contact inquiry, Offerings exploration
- **Voice constraints:** no influencer tone, no fear framing, no generic wellness cliches
- **Visual constraints:** editorial, spacious, restrained motion, high legibility
- **Color:** black/white dominant; accent color used sparingly and intentionally
- **Typography:** Cormorant-forward; Moulin used sparingly; logo stays all caps and smaller scale
- **Layout bias:** prefer left-justified compositions; center align only when clearly intentional
- **Template avoidance:** customize Squarespace styling to avoid default plugin look
- **Navigation scope (MVP):** Home, About, Offerings, Member Space, Contact

## 1) Home
### Role
- Threshold page: felt orientation in under 5 seconds.

### Primary Goal
- Move users to one intentional next step.

### Primary CTA
- `Become a Member`

### Secondary CTA (optional)
- `Explore Offerings`

### Required Sections
1. Hero media block (single image or short loop video)
2. 1-2 lines orientation copy
3. Single dominant CTA

### Suggested Copy Direction
- Reframe routine as supportive practices that evolve with the person.
- Keep copy minimal and intriguing, not explanatory.

### Squarespace Module Mapping
- Section: full-width image/video hero
- Section text overlay or adjacent text block
- Primary button block

### Done Criteria
- User can identify what TRS feels like and where to click next in under 5 seconds.

## 2) About
### Role
- Establish viewpoint, credibility, and human connection without overexplaining.

### Primary Goal
- Build trust and context for why TRS exists and how it is different.

### Primary CTA
- `Enter Member Space`

### Secondary CTA
- `View Offerings`

### Required Sections
1. Philosophy anchor statement
2. Short founder/practitioner introduction
3. Why Member Space + Method exists
4. Transition CTA block

### Suggested Copy Direction
- Reflection -> action -> embodied change.
- Soft structure as operating philosophy.

### Squarespace Module Mapping
- Rich text sections with clear hierarchy
- Image + text split for founder block
- CTA section with button

### Done Criteria
- User understands TRS origin, perspective, and pathway choices.

## 3) Offerings
### Role
- Convert curiosity into clear self-selection across offerings.

### Primary Goal
- Explain how care happens and route users to the right entry point.

### Primary CTA
- `Join Member Space`

### Secondary CTA
- `Contact TRS`

### Required Sections
1. Ecosystem overview (how offerings connect)
2. Member Space block (who for, value, outcome)
3. Method block (learning + body literacy framing)
4. Studio block (clear “Phase 02 / coming” positioning)
5. CTA decision strip

### Suggested Copy Direction
- World-building with practical clarity.
- Emphasize relief, confidence, and fit over hype.

### Squarespace Module Mapping
- Repeating stacked sections (image + text)
- Accordion/tabs only if clarity improves
- CTA strip with 1-2 buttons

### Done Criteria
- User can choose an entry path in one scroll without confusion.

## 4) Member Space
### Role
- Core conversion page for subscription container and Method access.

### Primary Goal
- Convert aligned visitors to members.

### Primary CTA
- `Become a Member`

### Secondary CTA
- `Log In` (existing members)

### Required Sections
1. Clear value proposition (what it is)
2. What’s included list
3. The Method relationship explanation
4. 2-4 testimonials
5. Preview mechanism (no full free trial; optional “Start Here” sample)
6. Final conversion CTA

### Suggested Copy Direction
- “See yourself in this” language with concrete outcomes.
- Keep invitation warm, specific, and non-performative.

### Squarespace Module Mapping
- Pricing/plan block (or custom section if needed)
- Feature list section
- Testimonial carousel/grid
- Button cluster for Join + Log In

### Done Criteria
- Benefits are unambiguous and signup path is friction-light.

## 5) Contact
### Role
- Fast, low-friction inquiry path.

### Primary Goal
- Capture qualified inquiries with minimal effort.

### Primary CTA
- `Send a Message`

### Required Sections
1. Brief invitation copy
2. Contact form (short)
3. Direct email display

### Suggested Copy Direction
- Direct, warm, and clear.

### Squarespace Module Mapping
- Form block
- Text block with direct email

### Done Criteria
- User can submit inquiry in under 60 seconds.

## QA Checklist Per Page
- Goal and CTA are obvious above the fold
- Language matches TRS voice and avoids banned phrasing
- Mobile spacing and hierarchy read cleanly
- Buttons/routes point to real destinations
- Accessibility basics covered (headings, contrast, alt text)
